# AppNexus (Xandr)

> AppNexus was a New York-based programmatic advertising technology company operating a real-time
> online ad exchange and a cloud-based buy-side and sell-side platform. Acquired by AT&T in 2018 and
> rebranded Xandr, and now part of Microsoft, its developer surface lives on as the Xandr Digital
> Platform API (host api.appnexus.com) plus the AppNexus mobile advertising SDKs. This llms.txt was
> generated by the API Evangelist enrichment pipeline from the public developer documentation.

## API
- [Digital Platform API](https://learn.microsoft.com/xandr/digital-platform-api/): RESTful JSON API for buy-side and sell-side ad operations, reporting, and platform management. Base URL https://api.appnexus.com.

## Conventions
- Authentication: username/password exchanged at POST /auth for a token (Authorization header or cookie); 2h idle / 24h hard expiry.
- Pagination: start_element / num_elements (max 100 per response).
- Response envelope: { "response": { "status": "OK", ... } }; errors carry error_id + error.
- Rate limiting: HTTP 429 with Retry-After; 15 concurrent-request cap.
- Versioning: URI-path (/current/ and /vX.Y/); breaking changes dual-versioned for 60 days.
